> Landing page for Dodo Festas e Eventos, an event catering business with custom menus, elegant presentation and close customer service.

🔗 **Live demo:** [dodofestaseeventos.vercel.app](https://dodofestaseeventos.vercel.app)

## ✅ Features

- [x] One-page layout with About, Services, Gallery, Highlights and Contact sections
- [x] Custom menus for themed events and receptions
- [x] Call-to-action buttons that open WhatsApp and email to request a quote
- [x] Floating WhatsApp button
- [x] Fully responsive with pure HTML and CSS

## 💻 Prerequisites

Before you begin, make sure you have:

- A modern web browser (Chrome, Firefox, Edge or Safari)
- [Git](https://git-scm.com/) installed

## 🚀 Installing Dodo Festas e Eventos

To install Dodo Festas e Eventos, follow these steps:

Linux and macOS:

```bash
git clone https://github.com/NathanCarvalhodaCunha/Dodo_Festas_e_Eventos.git
cd Dodo_Festas_e_Eventos
```

Windows:

```powershell
git clone https://github.com/NathanCarvalhodaCunha/Dodo_Festas_e_Eventos.git
cd Dodo_Festas_e_Eventos
```

## ☕ Using Dodo Festas e Eventos

To use Dodo Festas e Eventos, follow these steps:

Open `index.html` in your browser, or use the live demo. No build step is needed.
