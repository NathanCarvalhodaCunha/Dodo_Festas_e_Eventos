## ✨ Features

- 🏠 One-page layout with **About, Services, Gallery, Highlights and Contact** sections
- 🍽️ Presentation of custom menus for themed events and receptions
- 💬 **Call-to-action buttons** that open WhatsApp and email to request a quote
- 📱 Fully responsive, built with pure HTML and CSS (no frameworks)

## 🛠 Tech stack

- HTML5
- CSS3
- Deployed on Vercel

## ▶️ Running locally

```bash
git clone https://github.com/NathanCarvalhodaCunha/Dodo_Festas_e_Eventos.git
cd Dodo_Festas_e_Eventos
```

Then open `index.html` in your browser (no build step needed).
